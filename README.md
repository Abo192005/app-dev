# She's Dating the Gangster
> *"A love story between a good girl and a bad boy."*
## About the Movie
**She's Dating the Gangster** is a 2014 Filipino romantic comedy-drama film based on the Wattpad novel by Bianca Bernardino. It was directed by Cathy Garcia-Molina and produced by Star Cinema.
## Cast
1. Kathryn Bernardo as Athena Mariano
2. Daniel Padilla as Kenji Delos Reyes
